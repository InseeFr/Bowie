# Utilisation de nomenclatures dans Pogues

Les nomenclatures sont utilisées comme données d'entrées dans le composant de recherche sur liste (ou "Suggester") de Pogues. Plus de détails dans [la page dédié](1-suggester.md)

Les nomenclatures pour être utilisable par ce composant doivent contenir au moins les attributs/colonnes `id` et `label`.

## Page de Nomenclatures
On peut accéder à la page des nomenclatures via un bouton sur le menu à gauche. Cette page est en lecture seule, on ne peut donc pas éditer une nomenclature.

![alt text](../../../img/pogues/nomenclature-page.png)

!!! abstract "Légende"
    Pour chaque nomenclature, on dispose :

    1. du nom métier de la nomenclature : Nom dans le menu déroulant dans Pogues
    2. de sa version : Nom du fichier chargé dans Pogues
    3. des questions associées : Nom des id des questions qui utilisent cette nomenclature
