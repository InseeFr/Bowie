# Les Tableaux dans Pogues

Il existe deux type de tableaux : 

- les tableaux [Dynamiques](2-tableau-dynamique.md) ✨
- les tableaux [Statiques](1-tableau-statique.md)

!!! danger "Non supporté pour l'orchestrateur Queen (collecte enquêteur)"
    Les tableaux sont prévus pour la collecte en **mode web ménages et entreprises** et pas pour la collecte avec enquêteur pour laquelle le principe général est de poser une question par page (à l'exclusion des boucles et liens deux à deux).
