# L'utilisation du VTL dans Pogues

Cette section a pour but d'aider les utilisateurs de Pogues à utiliser le `VTL` dans leur questionnaires. Elle possède 3 parties : 

- [Fonctions VTL et usages](fonctions-vtl.md) : Liste des fonctions VTL et leur utilisation/fonctionnement
- [XPath et VTL, les différences](migration-xpath-vers-vtl.md) : Guide pour aider à la migration de la syntaxe `XPATH` (ancien questionnaires) à la syntaxe `VTL`
- [Guide VTL Pogues](vtl.md) : Guide l’utilisateur de Pogues dans son usage du langage VTL.
