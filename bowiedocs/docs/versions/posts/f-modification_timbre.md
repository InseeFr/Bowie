# ✨ Affecter un nouveau timbre à un questionnaire 

Une nouvelle fonctionnalité est proposée dans Pogues : pouvoir **changer le timbre associé à un questionnaire depuis la page Détail**.

Cette fonctionnalité permet de changer de timbre de façon autonome, notamment suite à la duplication d'un questionnaire.
De plus, lorsque l'on duplique un questionnaire, celui ci est maintenant **dupliqué par défaut dans son propre timbre**.

!!! example "Exemple"
    Par exemple : en tant que concepteur d'enquête, je souhaite m'inspirer du questionnaire d'une autre enquête contenant des éléments complexes que je souhaite m'approprier. Je duplique le questionnaire pour le manipuler sans gêner les autres utilisateurs. Avec la fonctionnalité de duplication, ce questionnaire va être dupliqué sous le timbre d'origine mais grâce à la nouvelle fonctionnalité je vais pouvoir lui affecter mon timbre pour le retrouver facilement chez moi.
