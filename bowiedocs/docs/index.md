# :octicons-zap-16: atelier de conception d'enquêtes

Bowie est un ensemble de solutions open-source et cohérentes permettant la création de questionnaires à travers le principe de [métadonnées actives](metadata/index.md).

##### Studio de conception de modèles de questionnaire - [Pogues :material-view-dashboard-edit-outline:](1._Pogues/index.md)
##### Générateur de questionnaires - [Eno :material-cog-outline:](3._Eno/index.md)
##### Bibliothèque de composants graphiques incluant un moteur de contrôle - [Lunatic :material-bookshelf:](4._Lunatic/index.md)
##### Solutions d'orchestration de ces composants pour le web - [Stromae :material-web:](5._Orchestrateurs/Stromae-DSFR/index.md) 
##### Solutions d'orchestration de ces composants pour la collecte par enquêteur - [Queen :material-account-voice:](5._Orchestrateurs/Queen/index.md)
##### Personnalisation pour une visualisation enrichie des questionnaires [Public-Enemy :material-brush-variant:](1._Pogues/🚀_Guide/Personnalisation/index.md)

Bowie est développé à l'Insee en [open-source :material-github:](https://github.com/InseeFr/Bowie). Il s'articule idéalement pour la mise en oeuvre de collectes de données avec la plateforme de collecte _open-source_ de l'Insee.
